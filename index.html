How to use Aircraft Modelling

This tool builds CAP 1732 taxiway obstacle surfaces: load a survey, lay out taxi routes, choose aircraft, and generate the obstacle points for CAD.

1 · Survey file

Load the surveyor's CAP 1732 export (.csv or .xlsx). HOLD points provide positions and orthometric elevations; CENTRE_PT_RWY builds the runway centreline; STANDs are shown for reference.

2 · Taxiway network

Connect the surveyed holds into taxiway routes, build the runway centreline from the survey, draw routes over imagery with hold-snapping, or import SHP/GeoJSON from CAD.

Drawing: click to add vertices (snaps to holds) · double-click or Enter to finish · Esc cancels.

Curves: select a route, then drag a diamond mid-segment handle sideways to bow that segment into an arc; right-click it to straighten; double-click it to split the segment (adds a vertex, so compound / S-curves can be fitted piece by piece). Right-click a round vertex to delete it.

3 · Aircraft types & verification

Dimensions are in metres, heights above ground; elevation = nearest hold ortho height + offset. Library LENGTH / WINGSPAN / TAIL_H are published figures; NOSE_TO_WING, NOSE_H and WING_H are conservative estimates — verify against the manufacturer's airport planning manual (cross-check at Eurocontrol's Aircraft Performance Database).

The table starts empty each project — pull in just the types you need from the built-in library (43 ACAP-extracted types plus regional estimates; hover a row for its source).

Every type must be signed off as checked against the manufacturer's ACAP before it can be used — editing any dimension clears that sign-off. Sign-offs are shared live with the whole team through the aircraft-data service: verifying a type here marks it verified for everyone, instantly. If the service is unreachable the tool works offline and sign-offs stay local until reconnected. CSV export/import remains for a controlled snapshot.

4 · Routes

Assign each route its aircraft type plus the runway and category used to group the export files (RUNWAY_CATEGORY.csv). Select a route to edit vertices: drag to move, right-click a vertex to delete.

5 · Generate & export

Station spacing = aircraft length + gap, matching the QGIS tool (length + 100 m). Set the radius, gap and hold-match tolerance, generate the obstacle points, then download the grouped CSVs (zip) or the validation workbook.

Projects

Save the whole project (survey, routes, aircraft table) to a file with Save project, and reload it later with Load project. Reset everything clears the session.
